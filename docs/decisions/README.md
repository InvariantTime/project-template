# Architectural decisions

Record a consequential accepted choice when its rationale or alternatives will matter later. Use [the decision template](template.md) and a descriptive filename such as `0001-contract-distribution.md`.

Use statuses **Proposed**, **Accepted**, **Superseded**, or **Rejected**. A proposed record does not establish a project requirement. Link an applicable GitHub Issue and related concepts when useful. Keep task progress in Issues rather than maintaining duplicate status here.
