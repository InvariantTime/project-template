# Project context

## Purpose

Provide a reusable starting point for projects in which people and coding agents collaborate using explicit project knowledge, repeatable commands, and visible task criteria.

## Current scope

The template includes development scripts, repository-local skills, GitHub Issues helpers, documentation conventions, and a CI workflow. It does not include a product implementation or select a backend/frontend stack.

## Success criteria

- A new contributor can find the product context and development commands.
- Scripts fail clearly when tools, hooks, authentication, or repository access are missing.
- Checks distinguish template validation from product verification.
- Domain meanings and consequential decisions remain discoverable.
- A task's acceptance criteria can be traced to observed verification.

## Adoption questions

Replace this page with the product's purpose, audience, first deliverable, boundaries, and unresolved choices. Record the chosen toolchain in `.dev/project.sh` and its setup in `.dev/docs/environment.md`.
